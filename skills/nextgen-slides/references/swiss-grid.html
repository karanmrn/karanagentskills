03 — MeasureLine Length & The Reading Rhythm●
03 / Measure
Too Narrow~ 28 characters

A column set too tight fractures the sentence. The eye snaps back before it gains momentum, and rhythm is lost.

Ideal45–75 characters

Between forty-five and seventy-five characters per line, the eye travels a comfortable arc and returns without hunting for the next row. This is the measure that reads as effortless — long enough for cadence, short enough to hold the line.

Too Wide~ 110 characters

When a line runs on far past its useful length, the return sweep grows unreliable and the reader loses the row — doubling back or skipping ahead — because the horizontal distance has simply outrun the eye's ability to find where the following line begins.

05 — ContrastDifference Does The Work●
95%
05 / Contrast

Make it
different, or
make it gone.

Roughly 95% of what we read online is set in type — which means the typographic decisions are the design. Weak contrast reads as no contrast: two headings a hair apart in size look like a mistake, not a system.

If two elements are not the same, make them clearly different.

06 — ManifestoSix Lines To Keep●

Set with
intention.

01Order over ornament. Structure carries meaning; decoration only borrows it.
02Choose the grid before the first word — then let every element answer to it.
03Respect the measure. Reading is a rhythm; protect the line's length.
04One scale, one voice. Let a single ratio speak for the whole system.
05Contrast with courage. If two things differ, make them differ clearly.
06White space is content. What you leave empty gives the rest its meaning.
