How the slides editor works
✎
Edit text in placeDouble-click any text on a slide, type, then press Enter (Esc to cancel). Changes save straight to the file.
💬
Comment for the agentSingle-click any element to attach a comment to it. Comments collect in the panel — hit Send to hand the batch to the agent, which edits the deck live.
‹›
NavigateUse ‹ / › in the top bar, or the arrow keys, to move between slides. The counter shows your place.
◈
PreviewOpens the deck in a clean new tab at the exact size it'll be presented — no editor chrome.
✓
Track your requestsEach sent request shows a badge: Queued → Working (spinner) → Done (✓). The bar below shows when the agent is Listening (green) or Working (amber spinner).
⏻
ContinueWhen a stage is finished, hit Continue — the agent hands over anything queued, stops listening, and moves on to the next step. Re-open the editor anytime to keep going.
Close the editor?

This finishes the current stage and tells the agent to stop listening for changes. Anything still in the queue will be handed over first. You can re-open the editor anytime to keep working.

Publish to the web

Upload this deck to a free public URL. Anyone with the link can view it.
